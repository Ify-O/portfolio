## Design Philosophy

This portfolio is designed to communicate professionalism, technical expertise and attention to detail.

Rather than following common technology portfolio trends, the interface adopts a premium editorial style inspired by luxury brands.

The objective is to allow the work itself to become the focal point while maintaining excellent usability and readability.

# Styling Philosophy

This project follows a hybrid styling architecture.

## Tailwind CSS

Used for:

- Layout
- Grid
- Flexbox
- Responsive utilities
- Spacing
- Positioning

---

## CSS

Used for:

- Reusable components
- Buttons
- Navigation
- Hero section
- Cards
- Footer
- Animations

---

## CSS Variables

Used for:

- Brand colours
- Typography
- Shadows
- Border radius
- Global spacing
- Design tokens

---

# Component Principles

Each React component should have a single responsibility.

Components should primarily describe structure rather than presentation.

Repeated styling should always be extracted into reusable CSS classes.

---

# Naming Convention

Examples:

.header

.hero

.hero-title

.hero-buttons

.card

.section-title

.btn

.btn-primary

.btn-outline

Naming should remain descriptive and consistent throughout the project.

---

# Responsive Philosophy

Desktop-first visual design.

Mobile-first implementation.

Every section should be responsive before moving to the next feature.

---

# Accessibility

The project should prioritise:

- Semantic HTML
- Keyboard navigation
- Colour contrast
- Readable typography
- Meaningful alt text
- Accessible interactive elements

Accessibility is considered a core requirement rather than a future enhancement.
