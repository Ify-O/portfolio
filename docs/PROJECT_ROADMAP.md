# Project Roadmap

This roadmap outlines the long-term vision for the portfolio.

It represents the current development plan and will evolve as new ideas, projects, and technologies are incorporated.

The portfolio itself is treated as an ongoing software project and will be improved continuously.

---

# Vision

Create a professional portfolio that showcases:

- Software development projects
- Cloud computing projects
- Technical case studies
- Certifications
- Professional experience
- Continuous learning

The portfolio should communicate not only what I have built but also how I approach solving problems from both business and technical perspectives.

---

# Phase 1 — Foundation

Objective

Build the project's technical foundation.

Tasks

- Initialise React application
- Install dependencies
- Configure routing
- Configure Tailwind CSS
- Configure DaisyUI
- Organise folder structure
- Initialise Git repository
- Create documentation

Status

🟡 In Progress

# Phase 3 — Projects

Objective

Transform the portfolio into a project showcase.

Each project will include:

- Overview
- Problem Statement
- Technologies Used
- Screenshots
- Architecture Diagram (where applicable)
- Challenges
- Lessons Learned
- GitHub Repository
- Live Demo

Projects will include both software development and cloud engineering work.

# Development Workflow

Each new project will follow the same lifecycle.

Plan

↓

Build

↓

Test

↓

Refactor

↓

Document

↓

Publish

↓

Add to Portfolio

This ensures consistency across every project showcased.

# Long-Term Goals

The portfolio should demonstrate:

- Clean code
- Good documentation
- Strong Git practices
- Scalable architecture
- Practical software development skills
- Cloud engineering knowledge
- Continuous professional growth

Rather than being a static website, the portfolio will serve as a living record of my technical journey and the solutions I build over time.
