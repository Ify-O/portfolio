# Personal Portfolio

A modern, responsive portfolio built with React, Vite, Tailwind CSS, and DaisyUI to showcase my software development, cloud computing, and technical projects.

This portfolio is more than a personal website—it's a living project that grows alongside my technical journey. Every feature, project, and improvement reflects practical experience, continuous learning, and my commitment to building solutions that solve real business problems.

---

## Tech Stack

### Frontend
- React
- JavaScript (ES6+)
- Vite
- React Router DOM

### Styling
- Tailwind CSS
- DaisyUI

### Development Tools
- Git
- GitHub
- ESLint

---
